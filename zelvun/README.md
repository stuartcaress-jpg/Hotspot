# Zelvun homepage preview

This folder contains a standalone, mobile-friendly homepage concept for the next phase of ZELVUN.

## Included
- Responsive dark-navy branding and category browsing
- Search across example content
- Three embedded YouTube players (using YouTube's privacy-enhanced embed host)
- Sample event and community cards
- Clear notices distinguishing demo content from working services

## Not yet connected
Accounts, group publishing, chat, real event registration, push notifications, Zelvun-hosted livestreaming, virtual gifts, payments and donations are not implemented in this static prototype.

## Preview
Once the repository's Vercel deployment picks up this branch's changes, the intended path is `/zelvun/` on the deployed site. A branch preview URL depends on the Vercel project settings and cannot be assumed until verified.

YouTube playback depends on the creator's embedding permissions and YouTube availability. Zelvun does not host these videos.
